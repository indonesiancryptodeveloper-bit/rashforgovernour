Rash For Gavernour (RFG) is a community-driven BEP20 branding token created to support awareness and digital movement for the Philippines gubernatorial election. Built on BNB Smart Chain for fast, low-cost transactions.

Disclaimer: RFG is a community branding / meme token for support and awareness purposes. It is NOT an official government token and NOT affiliated with COMELEC.
